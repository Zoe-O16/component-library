# Folded-corner sticker

**Status:** Partly guessed: some timing was not in the original code

**On FC Hyena:** Sticker component on Specials: a square card with a triangular corner mask (a 353×353 SVG triangle) in the brand colour. Its transition is 0.4 s on ease (.44, 0, .23, .98). How far the fold grows on hover is my guess.

**Mobile:** The fold grows on hover, so on touch screens it stays at its resting size. Partly guessed: the sticker's phone variant wasn't checked.

The specials carry a little folded corner. On hover the fold opens a bit wider, as if you were about to peel it back.

## Use it
1. Load `../../tokens.css` (or copy its variables).
2. Copy the markup from `index.html`.
3. Add `style.css`.

Open `index.html` to see a live demo.
