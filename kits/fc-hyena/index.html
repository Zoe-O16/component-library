Hyena Motion Kit

These are the animations on fchyena.nl, taken from the site's own Framer code and rebuilt from scratch in plain HTML, CSS and JS with no libraries. The durations, easing curves, delays and angles are the real values. From code means the effect and its numbers come straight from the site. Partly guessed means the effect is there, but some of its timing wasn't in the code. Reload the page and the highlight colour changes, just like on FC Hyena.

Mobile shows each demo at phone width. Touch-only changes (no hover, native scrolling) show on a real phone.
