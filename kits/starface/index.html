Starface Motion

These are the animations on starface.world, a Shopify shop built on the Dawn theme with no animation library. The values come from the theme's own CSS and JS and are rebuilt here from scratch in plain HTML, CSS and JS. Note that Dawn sets 1rem to 10px, so every value below is given in pixels. From code means the effect and its numbers come straight from the site. Partly guessed means the effect is there, but some of its values weren't in the code. Starface's motion is quick and functional: 0.1, 0.2 and 0.5 s on plain ease, with one burst of star confetti on top.

Mobile shows each demo at phone width, so the site's 750 and 990 px breakpoints apply.
